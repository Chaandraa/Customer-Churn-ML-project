# Customer Churn Prediction System

Predict customer churn using Machine Learning and provide business insights through an interactive Streamlit application.

---

## Project Overview

Customer churn directly impacts business growth and revenue.

This project analyzes customer purchasing behavior and predicts whether a customer is likely to churn using Machine Learning models.

The system includes:
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Model training
- Model evaluation
- Streamlit application for predictions

---

## Objective

Build an end-to-end Machine Learning pipeline that helps identify customers at risk of leaving and supports customer retention decisions.
